# Predicting the 2023 Formula One Season

**Published:** 2023

[Read the original article](https://www.bruinsportsanalytics.org/journalism/predicting-the-2023-formula-one-season)

This project includes my original R analysis used for the published article. The script filters historical Formula One driver standings, fits linear and quadratic regression models, visualizes driver standings over time, and generates 2023 predictions.

- [Original R analysis](f1%20analyses-updated-0302.r)

The script references a `driver_standings` data frame that is not included here, so it cannot be run standalone without the original data preparation.
